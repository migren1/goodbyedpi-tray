# dpi — GoodbyeDPI görev çubuğu aç/kapa

GoodbyeDPI'yi terminal penceresi açmadan görev çubuğundan (tray) aç/kapa yapan araç. Native .NET/WPF; hedef: goodbyedpi gömülü tek installer.

## İçindekiler
- Yapılanlar / durum → `.claude/bilgi/yapildi.md`
- Açık işler → `.claude/bilgi/acik-isler.md`

## Hızlı
- App kaynağı: `app/` · Build: `C:\Users\user\.dotnet\dotnet.exe build -c Release` (app içinde)
- Çıktı: `app/bin/Release/net8.0-windows/GoodbyeDPI.exe` (admin ister)
- goodbyedpi kaynağı: `C:\Users\user\Documents\goodbyedpi-0.2.3rc3-2\...`
- Installer script: `installer/installer.iss`
